# Nova Era Barber

Site de uma página da barbearia Nova Era Barber, feito em HTML, CSS e JavaScript puros, sem dependências.

## O que tem

- Tela de boas-vindas de 3 segundos ao abrir a página
- Serviços com busca e ordenação
- Galeria de trabalhos (espaços reservados para as fotos)
- Agendamento com serviço, dia e horário, e abertura do WhatsApp com a mensagem pronta
- Botão flutuante animado "Agendar horário"
- Efeitos nos botões (elevação, brilho, clique e foco), com suporte a "reduzir movimento"

## Como abrir

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Observações

- O agendamento é uma demonstração: as reservas ficam salvas só no navegador (localStorage).
- As fotos são painéis de exemplo. Para usar imagens reais, troque os blocos `.ph` por `<img>`.
- O número do WhatsApp fica na variável `WA` no final do `index.html`.
